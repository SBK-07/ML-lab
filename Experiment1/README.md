# Experiment 1: Exploratory Data Analysis & Machine Learning Benchmarks

## Overview
This experiment introduces Exploratory Data Analysis (EDA) and basic machine learning workflows across five diverse datasets: Iris, Diabetes, Email Spam, MNIST digit recognition, and Loan Sanction Amount Prediction.

## Key Objectives
- Practice loading, cleaning, and inspecting structured data.
- Analyze missing values, summary statistics, feature distributions, and outlier patterns.
- Visualize features using histograms, boxplots, scatter plots, and correlation heatmaps.
- Implement baseline machine learning pipelines for classification and regression tasks.

## Datasets & Notebooks Included
1. **Iris (`Iris.ipynb`)**: Multi-class flower species classification.
2. **Diabetes (`Diabetes.ipynb`)**: Binary medical outcome prediction.
3. **Email Spam (`Email_Spam_Classification.ipynb`)**: Text-derived numerical feature classification.
4. **MNIST (`MNIST.ipynb`)**: Handwritten digit classification.
5. **Loan Sanction Amount (`Loan_Sanction_Amount_Prediction.ipynb`)**: Regression baseline for continuous loan amount estimation.
